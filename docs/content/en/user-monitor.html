The monitor sidecar records metrics periodically (kubectl top, nvidia-smi) and displays charts in the UI.

Prerequisites

  • Server is running with the monitor sidecar (enabled on spawn).
  • Cluster has metrics-server installed.

Controls

  • Pod — select pod.
  • Range — 5 min, 15 min, 30 min, 1 hour, 5 hours.
  • Refresh / Download — download JSONL metrics log.

Summary cards: CPU, RAM, GPU, GPU memory.
