Monitor tài nguyên
Resource monitor

CPU, RAM, GPU từ sidecar monitor-sidecar.
CPU, memory, and GPU usage for a running server.

Sidecar monitor ghi metrics định kỳ (kubectl top, nvidia-smi) và hiển thị biểu đồ trên UI.

Điều kiện

  • Server đang chạy với monitor sidecar (bật khi spawn).
  • Cluster có metrics-server.

Điều khiển

  • Pod — chọn pod.
  • Range — 5 min, 15 min, 30 min, 1 hour, 5 hours.
  • Refresh / Download — tải JSONL log metrics.

Thẻ tóm tắt: CPU, RAM, GPU, GPU memory.

The monitor sidecar records metrics periodically (kubectl top, nvidia-smi) and displays charts in the UI.

Prerequisites

  • Server is running with the monitor sidecar (enabled on spawn).
  • Cluster has metrics-server installed.

Controls

  • Pod — select pod.
  • Range — 5 min, 15 min, 30 min, 1 hour, 5 hours.
  • Refresh / Download — download JSONL metrics log.

Summary cards: CPU, RAM, GPU, GPU memory.
