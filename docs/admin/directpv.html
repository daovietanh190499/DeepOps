DirectPV discover & init
DirectPV discover & init

Khám phá ổ đĩa raw và khởi tạo cho DirectPV (xóa dữ liệu ổ).
Discover raw drives and initialize DirectPV (destructive).

Cảnh báo: Init drives format và xóa toàn bộ dữ liệu trên ổ được chọn. Chỉ chọn ổ dành riêng cho DirectPV, không phải OS disk.

Discover

  1. Admin → Overall → mục DirectPV discover.
  2. Discover — chạy kubectl directpv discover, hiển thị bảng ổ: Name, Size, Make, FS, ID.
  3. Cột Select — toggle yes / no cho từng ổ cần init.

Init

  1. Init drives — modal Initialize DirectPV drives?
  2. Yes, init drives — chạy kubectl directpv init … --dangerous.

Sau init, StorageClass directpv-min-io sẵn sàng cho PVC drive/user.

CLI tương đương

kubectl directpv discover --output-file /tmp/directpv-drives.yaml
# chỉnh selected: true
kubectl directpv init /tmp/directpv-drives.yaml --dangerous
Warning: Init drives formats and erases all data on selected disks. Only select disks dedicated to DirectPV — not the OS disk.

Discover

  1. Admin → Overall → DirectPV discover section.
  2. Discover — runs kubectl directpv discover; shows disk table: Name, Size, Make, FS, ID.
  3. Select column — toggle yes / no for each disk to initialize.

Init

  1. Init drives — opens Initialize DirectPV drives? modal.
  2. Yes, init drives — runs kubectl directpv init … --dangerous.

After init, StorageClass directpv-min-io is ready for user drive PVCs.

Equivalent CLI

kubectl directpv discover --output-file /tmp/directpv-drives.yaml
# set selected: true
kubectl directpv init /tmp/directpv-drives.yaml --dangerous
