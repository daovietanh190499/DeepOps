Expose port (wstunnel)
Expose port (wstunnel)

Mở cổng TCP trong container qua HTTPS/WSS trên domain hub.
Forward TCP ports through the hub wstunnel proxy.

Sidecar port-tunnel (wstunnel) cho phép truy cập cổng TCP của container chính qua URL dạng:

wss://<hub-domain>/<username>/<slug>/port-tunnel

Điều kiện

  • Server đang Running.
  • Chart deploy với portTunnel.enabled=true (hub bật sidecar khi spawn).

Các bước

  1. Mở modal chi tiết server → tab General.
  2. Cuộn tới Exposing port through websocket tunnel.
  3. Nhập Container ports — ví dụ 3000, 8000, 5432.
  4. Nhấn Expose (loading Applying…).
  5. Phần How to connect (wstunnel client) hiển thị WSS URL và mapping từng port.

SSH (cổng 22 / 2222)

Nếu image expose SSH, mục SSH via stdio tunnel cung cấp ProxyCommand wstunnel và snippet ~/.ssh/config. URL WebSocket dùng host hub, path -P user/slug/ssh-tunnel — không gắn path vào URL wss://.

The port-tunnel sidecar (wstunnel) lets you reach TCP ports on the main container via a URL like:

wss://<hub-domain>/<username>/<slug>/port-tunnel

Prerequisites

  • Server is Running.
  • Chart deployed with portTunnel.enabled=true (hub enables the sidecar on spawn).

Steps

  1. Open the server detail modal → General tab.
  2. Scroll to Exposing port through websocket tunnel.
  3. Enter Container ports — e.g. 3000, 8000, 5432.
  4. Click Expose (shows Applying… while processing).
  5. How to connect (wstunnel client) shows the WSS URL and per-port mappings.

SSH (ports 22 / 2222)

If the image exposes SSH, SSH via stdio tunnel provides a wstunnel ProxyCommand and a ~/.ssh/config snippet. The WebSocket URL uses the hub host with path -P user/slug/ssh-tunnel — do not append the path to the wss:// URL.
