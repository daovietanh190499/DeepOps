The admin Overall tab shows cluster information and operations tools.

Cluster information

  • Server version / Client version — Kubernetes versions.
  • Nodes, Namespaces — quick stats.
  • Join new node — Get join command runs microk8s add-node; Copy the join command.

Kubernetes nodes

Table columns: Name, Status, Roles, Internal/External IP, Version, OS, CPU, Memory.

SSH nodes

Manage machines outside the cluster (health check, admin terminal):

  • Add SSH node — Label, Host, Port, Username.
  • Hub SSH manager public key — copy/regenerate key to add to remote authorized_keys.

DirectPV drives (read-only list)

Output of kubectl directpv list drives — preview before discover/init; details at DirectPV discover & init.
