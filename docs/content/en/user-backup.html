Sidecar backup dùng rclone đồng bộ thư mục đã mount lên remote (Google Drive, S3, …).

Cấu hình

  1. Tab Backup trên modal server.
  2. Cron schedule — ví dụ 0 2 * * * (2h sáng hàng ngày).
  3. Remote destination — ví dụ gdrive:backups/my-server.
  4. rclone.conf — dán config remote → Save settings.
  5. Chọn Volumes to backup (checkbox theo mount).

Hành động

NútTác dụng
Schedule / Update scheduleĐẩy config + enable cron trong sidecar
Backup nowChạy rclone ngay (kubectl exec sidecar)
Stop backupDừng cron; sidecar container vẫn chạy
