The backup sidecar uses rclone to sync mounted directories to remote storage (Google Drive, S3, …).

Configuration

  1. Open the Backup tab in the server modal.
  2. Cron schedule — e.g. 0 2 * * * (2 AM daily).
  3. Remote destination — e.g. gdrive:backups/my-server.
  4. rclone.conf — paste remote config → Save settings.
  5. Select Volumes to backup (checkbox per mount).

Actions

ButtonEffect
Schedule / Update schedulePush config and enable cron in the sidecar
Backup nowRun rclone immediately (kubectl exec into sidecar)
Stop backupStop cron; sidecar container keeps running

Status values: Running…, Success, Failed, No run yet.
