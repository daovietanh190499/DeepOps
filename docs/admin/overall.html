Cluster overall
Cluster overall

Tổng quan cluster, join node, SSH nodes, DirectPV drives.
Cluster info, join nodes, SSH, and DirectPV drive list.

Tab Overall (admin) hiển thị thông tin cluster và công cụ vận hành.

Cluster information

  • Server version / Client version — phiên bản Kubernetes.
  • Nodes, Namespaces — thống kê nhanh.
  • Join new node — Get join command chạy microk8s add-node, Copy lệnh join.

Kubernetes nodes

Bảng: Name, Status, Roles, Internal/External IP, Version, OS, CPU, Memory.

SSH nodes

Quản lý máy SSH ngoài cluster (health check, terminal admin):

  • Add SSH node — Label, Host, Port, Username.
  • Hub SSH manager public key — copy/regenerate key để thêm vào authorized_keys remote.

DirectPV drives (read-only list)

Bảng output kubectl directpv list drives — xem trước khi discover/init chi tiết tại DirectPV discover & init.
