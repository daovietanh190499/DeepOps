A drive is a persistent volume on the cluster (StorageClass directpv-min-io). Each drive belongs to one user and can be mounted to one or more servers when creating a workspace.

Prerequisites

  • Signed in with GitHub and your account has been Accepted by an admin.
  • You have not exceeded the drive limit for your resource group (shown as Drives: n / max when a limit applies).

Create a new drive

  1. Open Dohub → My drives tab.
  2. Click Create drive.
  3. Fill in the form:
    • Name — display name (e.g. docs-demo-drive for testing).
    • Size — capacity from the admin catalog (e.g. 20Gi, 100Gi).
  4. Click Create drive (shows Creating… while processing).
Note: For docs or demos, use names prefixed with docs-demo- and delete them when finished. Do not delete a drive that is in use by a running server.

Bulk create drives

The Bulk create drive button opens a modal supporting JSON or CSV:

[{"name":"docs-demo-a","size":"20Gi"},{"name":"docs-demo-b","size":"20Gi"}]

CSV header: name,size

Delete a drive

  1. On the drive card, click Delete drive (disabled if the drive is bound to a running server).
  2. In the Delete drive modal, type delete to confirm.
  3. Click Delete.
