Overleaf chạy như workspace Dohub, truy cập overleaf.hub.example.com (or your workspace subdomain).

User — đăng nhập

  1. Mở URL Overleaf.
  2. Chọn đăng nhập SSO / Keycloak (tùy cấu hình instance).
  3. Sign in tài khoản đã được admin accept trên Dohub (nếu liên kết) hoặc tài khoản Keycloak.

User — chờ quyền

Lần đầu có thể thấy thông báo không đủ quyền — admin cần add user vào group Keycloak (và/hoặc group Overleaf internal).

  1. Liên hệ admin.
  2. Sau khi được add vào group (ví dụ overleaf-users), đăng xuất và đăng nhập lại.
  3. Tạo project LaTeX mới hoặc mở project được share.

Admin — add user vào group

  1. Keycloak admin → realm Overleaf → Groups.
  2. Chọn group có quyền sử dụng (ví dụ overleaf-users).
  3. Members → Add member → tìm user (demo: daovietanh19).
  4. User refresh trang Overleaf.
Server Overleaf trên Dohub spawn từ template Docker tùy chỉnh; đảm bảo image đã accepted trong tab Images.
