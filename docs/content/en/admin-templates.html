Admin → Servers → Catalog

Quick templates

Each template includes: Name, CPU, RAM, GPU, icon, Docker image/tag, ports, mount paths, file mounts, env defaults, active flag.

Add a template

  1. Fill the inline row or click Add template.
  2. Mount paths — e.g. /home/coder, /app/data.
  3. Default file mounts — upload small files + mount path.
  4. Environment defaults — JSON; supports {{username}} token.

Edit / delete

  • Edit — full modal with Sort order, Active.
  • Delete — remove template.
  • Download JSON / Import (JSON/CSV) — bulk operations.

Equipment catalogs

CPU, RAM, and GPU options for user form dropdowns:

  • CPU: 0.5, 2, … → Add.
  • RAM: 4G, 8G, …
  • GPU: 1:1024 (count:MiB VRAM).
