User có thể đề xuất Docker image mới để dùng khi tạo server. Image ở trạng thái pending cho đến khi admin Accept.

Đăng ký image

  1. Tab My images.
  2. Điền:
    • Label — tên hiển thị (ví dụ My Overleaf).
    • repository/name — ví dụ myregistry/overleaf.
    • Default tag — ví dụ latest.
    • Tags (comma-separated) — các tag khác: latest,5.0.0.
  3. Submit image.

Theo dõi trạng thái

StatusÝ nghĩa
pendingChờ admin duyệt — chưa chọn được trong form Create server
acceptedĐã duyệt — xuất hiện trong combobox Docker image

Xóa image đã submit

Cột Actions → Delete (chỉ image do bạn tạo).

Admin duyệt tại tab Images — xem Docker images (admin).
