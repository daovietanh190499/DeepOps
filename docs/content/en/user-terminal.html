Tab Terminal mở shell tương tác trong container chính (codehub) qua WebSocket + kubectl exec -it.

Prerequisites

  • Server Running và có pod Ready.
  • Hub pod có quyền exec vào namespace workspace.

Sử dụng

  1. Tab Terminal.
  2. Pod — chọn pod đang chạy.
  3. Shell — bash hoặc sh (theo exec_shell workspace).
  4. Reconnect — kết nối lại sau khi đổi pod/shell.

Phím tắt

  • Ctrl+C — gửi SIGINT (nếu không có selection).
  • Ctrl+V — dán từ clipboard.
  • Ctrl+C với text đã chọn — copy (không gửi interrupt).
