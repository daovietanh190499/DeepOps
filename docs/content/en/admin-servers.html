The Servers sub-tab lists all workspaces system-wide with owner @username.

Filters

  • Username, server name, resource group.

Actions

  • Start / Stop / Delete — same as user view.
  • Click a card → detail modal (logs, terminal, …) like the user view.
  • Bulk: Start servers, Stop servers, Delete servers with confirmation.

The Catalog sub-tab manages templates and equipment — see Server templates.
