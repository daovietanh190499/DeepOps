A server (workspace) is a codehub Helm release on Kubernetes: a main container (usually code-server), its own ingress, and optional sidecars (monitor, backup, wstunnel).

Overview

  1. Create server — saves configuration to the database (pod not running yet).
  2. Start — Helm install/upgrade; creates pod and ingress.
  3. Stop — removes the release; keeps configuration.
  4. Edit — only when the server is offline.
  5. Delete — removes the workspace and release (if any).

Create from a quick template

  1. My servers tab → Create server.
  2. Under Quick templates, click a template (Lollipop, Oreo, …) to pre-fill CPU, RAM, GPU, image, and mounts.
  3. Review the form below, then click Create server.

The Current specifications panel summarizes the config; Export JSON downloads the configuration file.

Edit a server

  1. Stop the server first (required).
  2. Open the server card or modal → Edit (or reopen Create server in edit mode).
  3. Change fields → Save changes.

Start / Stop

  • Start — deploys the pod; workspace URL appears when Running.
  • Stop — runs helm uninstall; data on drive PVCs is preserved.

Delete a server

  1. Stop first (recommended).
  2. Delete icon on the card → type delete → Delete.

Bulk create servers

Bulk create server — JSON/CSV for multiple servers; optional Start servers after create.

[{"name":"docs-demo-ws","cpu":2,"ram":"4G","drive_mounts":[{"drive_id":"<uuid>","mount_path":"/home/coder"}],"docker_repository":"codercom/code-server","docker_tag":"4.89.0-ubuntu"}]
Important: Do not modify or delete production servers. For demos, create docs-demo-* resources and remove them immediately.
