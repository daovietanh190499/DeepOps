Quản trị viên

Resource groups

Giới hạn tài nguyên, quyền privileged và custom domain theo nhóm.

Admin → Users → Groups

Tạo group

  • Group name
  • Max CPU (vCPU), Max RAM (GB), Max drive (Gi), Max GPU VRAM (GB)
  • Max servers, Max drives, Max images (0 = unlimited)
  • Allow privileged pods
  • Allow custom service domain

Members

  1. Members trên card group.
  2. Add member — gõ username/email.
  3. Bulk add by email — nhiều email mỗi dòng.
  4. Remove — gỡ thành viên.

Mỗi user chỉ thuộc một group.
