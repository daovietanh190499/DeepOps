Logs

  1. Mở server → tab Logs.
  2. Chọn Pod (nếu nhiều pod).
  3. Chọn Container — container chính codehub hoặc All (prefixed).
  4. Refresh hoặc đợi auto-refresh 2 giây.

Nguồn: kubectl logs qua API hub.

Describe

  1. Tab Describe.
  2. Refresh để tải output kubectl describe deployment,pod.

Hữu ích khi debug scheduling, events, probe failed, mount volume.
