Overleaf runs as a Dohub workspace; access it at overleaf.example.com (or your workspace subdomain).

User — sign in

  1. Open the Overleaf URL.
  2. Choose SSO / Keycloak login (depends on instance config).
  3. Sign in with an account accepted on Dohub (if linked) or a Keycloak account.

User — waiting for access

On first login you may see insufficient permissions — an admin must add you to a Keycloak group (and/or Overleaf internal group).

  1. Contact an admin.
  2. After being added to a group (e.g. overleaf-users), sign out and sign in again.
  3. Create a new LaTeX project or open a shared project.

Admin — add user to group

  1. Keycloak admin → Overleaf realm → Groups.
  2. Select the access group (e.g. overleaf-users).
  3. Members → Add member → find user (demo: daovietanh19).
  4. User refreshes the Overleaf page.
The Overleaf server on Dohub is spawned from a custom Docker template; ensure the image is accepted under the Images tab.
