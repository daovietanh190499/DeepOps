Admin → Users → Groups

Create a group

  • Group name
  • Max CPU (vCPU), Max RAM (GB), Max drive (Gi), Max GPU VRAM (GB)
  • Max servers, Max drives, Max images (0 = unlimited)
  • Allow privileged pods
  • Allow custom service domain

Members

  1. Click Members on the group card.
  2. Add member — enter username/email.
  3. Bulk add by email — one email per line.
  4. Remove — remove a member.

Each user belongs to exactly one group.
