Logs

  1. Open a server → Logs tab.
  2. Select Pod (if multiple pods).
  3. Select Container — main codehub container or All (prefixed).
  4. Click Refresh or wait for auto-refresh every 2 seconds.

Source: kubectl logs via the hub API.

Describe

  1. Open the Describe tab.
  2. Click Refresh to load kubectl describe deployment,pod output.

Useful for debugging scheduling, events, failed probes, and volume mounts.
