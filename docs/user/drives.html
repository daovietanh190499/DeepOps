Tạo và xóa drive
Create & delete drives

Quản lý volume DirectPV gắn vào workspace (code-server / ứng dụng).
Manage DirectPV volumes attached to workspaces.

Drive là volume lưu trữ bền vững trên cluster (StorageClass directpv-min-io). Mỗi drive thuộc về một user và có thể mount vào một hoặc nhiều server khi tạo workspace.

Điều kiện

  • Đã đăng nhập GitHub và được admin Accept tài khoản.
  • Chưa vượt giới hạn số drive của resource group (hiển thị Drives: n / max nếu có giới hạn).

Tạo drive mới

  1. Mở Dohub → tab My drives.
  2. Nhấn Create drive.
  3. Điền form:
    • Name — tên hiển thị (ví dụ docs-demo-drive cho mục đích thử nghiệm).
    • Size — dung lượng từ catalog admin (ví dụ 20Gi, 100Gi).
  4. Nhấn Create drive (loading: Creating…).
Lưu ý: Khi viết tài liệu hoặc demo, dùng tên có tiền tố docs-demo- và xóa ngay sau khi xong. Không xóa drive đang được server đang chạy sử dụng.

Bulk create drive

Nút Bulk create drive mở modal hỗ trợ JSON hoặc CSV:

[{"name":"docs-demo-a","size":"20Gi"},{"name":"docs-demo-b","size":"20Gi"}]

CSV header: name,size

Xóa drive

  1. Trên thẻ drive, nhấn Delete drive (bị vô hiệu nếu drive đang bound bởi server đang chạy).
  2. Modal Delete drive yêu cầu gõ delete để xác nhận.
  3. Nhấn Delete.
