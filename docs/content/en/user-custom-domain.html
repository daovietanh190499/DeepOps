By default, workspace URLs follow https://{slug}-{username}.{DOMAIN_NAME}/. Users in a group with Allow custom service domain can override the hostname.

For users with permission

  1. When Create server / Edit server, set Service domain (ingress host) — e.g. myapp.example.com.
  2. DNS must point to the cluster ingress.
  3. The General tab shows Service domain with a copy button.

Grant permission (admin)

Users → Groups → Edit group → enable Allow custom service domain. See Resource groups.

TLS: Each hostname needs a valid certificate (Let's Encrypt HTTP-01 or wildcard DNS-01).
