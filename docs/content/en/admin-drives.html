The admin Drives tab has two sub-tabs: Drives and Size options.

Drives

  • Filter by username, drive name, resource group.
  • Drive cards show owner, size, and bound status.
  • Delete — remove a user's drive (use caution if in use).
  • Bulk: select multiple → Delete / Clear.

Size options

Catalog of drive sizes in the Create drive form:

  • Add size: enter e.g. 100Gi → Add size.
  • Hide/show or remove existing options.
