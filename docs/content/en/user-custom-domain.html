Mặc định URL workspace: https://{slug}-{username}.{DOMAIN_NAME}/. User trong group có Allow custom service domain có thể ghi đè hostname.

Users with permission

  1. Khi Create server / Edit server, điền Service domain (ingress host) — ví dụ myapp.example.com.
  2. DNS phải trỏ tới ingress cluster.
  3. Tab General hiển thị Service domain với nút copy.

Admin grants permission

Users → Groups → Edit group → enable Allow custom service domain. See Resource groups.

TLS: Mỗi hostname cần certificate phù hợp (Let's Encrypt HTTP-01 hoặc wildcard DNS-01).
