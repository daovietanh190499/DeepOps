Administrator

Docker images (admin)
Docker images

Đăng ký image, accept submission của user, import/export.
Approve or reject user-submitted images.

Admin → Images

Thêm image (admin)

Form giống user nhưng Add image — thường ở trạng thái accepted ngay.

Accept image của user

  1. Filter Pending.
  2. Hàng user submit → Accept.
  3. Hoặc bulk Accept nhiều image.

Chỉnh sửa

  • Edit — label, repository, tags, Active yes/no.
  • Delete — gỡ image khỏi catalog.

Import / Export

Download JSON, Import (JSON/CSV) — đồng bộ catalog giữa môi trường.

Admin → Images

Add image (admin)

Same form as users but Add image — typically accepted immediately.

Accept user-submitted images

  1. Filter Pending.
  2. On a user submission row → Accept.
  3. Or bulk Accept for multiple images.

Edit

  • Edit — label, repository, tags, Active yes/no.
  • Delete — remove image from catalog.

Import / Export

Download JSON, Import (JSON/CSV) — sync catalog between environments.
