The Terminal tab opens an interactive shell in the main container (codehub) via WebSocket and kubectl exec -it.

Prerequisites

  • Server is Running with a Ready pod.
  • The hub pod has exec permission in the workspace namespace.

Usage

  1. Open the Terminal tab.
  2. Pod — select the running pod.
  3. Shell — bash or sh (per workspace exec_shell).
  4. Reconnect — reconnect after changing pod or shell.

Keyboard shortcuts

  • Ctrl+C — send SIGINT (when no text is selected).
  • Ctrl+V — paste from clipboard.
  • Ctrl+C with selected text — copy (does not send interrupt).
The Connecting… status is shown outside the terminal area to avoid cursor offset in the prompt.
