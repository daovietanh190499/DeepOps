Users can submit new Docker images for use when creating servers. Images stay pending until an admin Accepts them.

Register an image

  1. Open the My images tab.
  2. Fill in:
    • Label — display name (e.g. My Overleaf).
    • repository/name — e.g. myregistry/overleaf.
    • Default tag — e.g. latest.
    • Tags (comma-separated) — additional tags: latest,5.0.0.
  3. Click Submit image.

Track status

StatusMeaning
pendingAwaiting admin approval — not selectable in Create server
acceptedApproved — appears in the Docker image combobox

Delete a submitted image

Actions column → Delete (only for images you created).

Admins approve images under Images — see Docker images (admin).
